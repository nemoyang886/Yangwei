# 杨威｜个人展示页

这是一份克制、真实的个人介绍。页面像一封写给朋友的信，从性格、运动和一次亲身经历讲起，说明杨威如何重新认识保险、为什么作出职业转型，以及他长期看重的几件事。

## 设计方向

- 使用 Hallmark 的 Letter 宏观结构与 Garden 色彩方向
- 视觉基调为暖纸色、墨绿文字和少量陶土橙，色彩集中在 `tokens.css`
- 只使用一张真实个人肖像，作为正文旁注而不是营销主视觉
- 内容以人物经历和做事方式为主，不设置产品展示或销售入口
- 去掉卡片墙、章节编号、横向轮播和全页滚动上浮动画
- 支持深色模式，并验证 320、375、414、768 和桌面宽度

## 本地预览

在当前目录运行

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
