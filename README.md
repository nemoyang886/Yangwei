# 杨威 Leo｜个人叙事页

这不是一份把经历按年份排好的简历，而是一页给朋友、客户与合作伙伴看的“认识杨威入口”。页面围绕三条主线展开：长期主义、保险主业的工作态度，以及把复杂问题规划成清晰路径的能力。

## 设计与内容

- 视觉概念：拳击训练日志 × 人生规划蓝图
- 统一配色：墨蓝、规划蓝、手绷带红、高亮黄、粉笔白
- 视觉素材：只使用一张个人肖像，其余图形全部由 CSS 与内联 SVG 绘制
- 公开边界：只展示公开项目与匿名方法，不上传客户资料和内部原始材料
- 适配范围：桌面端、手机端、系统深色模式、减少动态效果与高对比度偏好

## 本地预览

在当前目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
