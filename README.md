# 杨威｜个人展示页

这是一份克制、真实的个人介绍。页面从一次亲身经历讲起，说明杨威如何重新认识保险、为什么作出职业转型，以及他长期看重的几件事。

## 设计方向

- 视觉基调为暖白、石墨黑、沉静墨绿和少量暖橙
- 只使用一张个人肖像，其余视觉由排版与 CSS 图形完成
- 内容以人物经历和做事方式为主，不设置产品展示或销售入口
- 顶部导航使用单层半透明材质，内容卡片保持实体层级
- 五项长期投入支持鼠标、触控、键盘和按钮浏览
- 支持深色模式、减少动态效果、减少透明度和高对比度偏好

## 本地预览

在当前目录运行

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
