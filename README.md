# 杨威 Leo｜个人叙事页

这是一份轻松、克制的个人说明。它不负责证明杨威有多厉害，只记录一个快四十岁的武汉男人走过的路、现在做的事、身上的矛盾，以及和他相处时可能有用的几条说明。

## 设计与内容

- 视觉概念：拳击训练日志 × 个人生活手记
- 统一配色：墨蓝、规划蓝、手绷带红、高亮黄、粉笔白
- 视觉素材：只使用一张个人肖像，其余图形全部由 CSS 与内联 SVG 绘制
- 内容口径：少一点职业包装，多一点真实、不完美和生活感
- 公开边界：不上传客户资料、内部原始材料和私人敏感信息
- 适配范围：桌面端、手机端、系统深色模式、减少动态效果与高对比度偏好

## 本地预览

在当前目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
